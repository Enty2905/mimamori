## Navigation regressions repaired

- Auth demo JSX had literal whitespace outside a native Text element. Removed
  it and added a native JSX text scan to the mobile checks.
- The family-selection Zustand hook used a lowercase name. React Compiler
  could treat its invocation as an ordinary function and memoize the internal
  hook calls. Renamed it to `useFamilySelection`, used explicit selectors and
  stable effect dependencies. Navigation tests exercise the real selection hook
  and all tabs for both roles, including a changed account and repeated visits.
- Added a separate Jest run with the Metro/Android React Compiler caller. The
  ordinary component suite alone did not reproduce the compiler regression.
- Native testing found that Check-in kept its old scroll position after Next,
  hiding the next question's heading. The question ScrollView now resets to the
  top without animation whenever the step changes (Next or Back).

## Local native build

- Expo SDK 58 / RN 0.88 retained. Native Android files are generated by Expo.
- CMake's inherited 1024-character object path limit exceeded Windows Ninja's
  effective limit. An Expo config plugin sets 240 for native libraries, 250 for
  the app and uses the ignored workspace `.cxx/` directory for shorter staging
  paths, so CMake can hash long paths without exceeding Ninja's limit.
  See [CMake documentation](https://cmake.org/cmake/help/latest/variable/CMAKE_OBJECT_PATH_MAX.html)
  and [Reanimated Windows guidance](https://docs.swmansion.com/react-native-reanimated/docs/guides/building-on-windows/).
- Local preview explicitly enables loopback HTTP only in the API client and
  Android cleartext traffic in the generated manifest. Normal release remains
  HTTPS-only. Build flags: `MIMAMORI_LOCAL_BUILD=1`,
  `EXPO_PUBLIC_LOCAL_PREVIEW=true`, `EXPO_PUBLIC_DEMO_MODE=true`,
  `EXPO_PUBLIC_API_URL=http://127.0.0.1:18080`.
- Target: connected Xiaomi M2101K7BG, Android 13, arm64-v8a. A standalone local
  release APK embeds JavaScript; API access uses the PC backend through USB
  reverse port 18080. This is a local test binary, not a store release.
- Original generated Android folder and keystore preserved under ignored
  `.git/codex-checks/2026-11-16/native-install/original-android`.
- Android backup is disabled for the app's local health data.
- Expo Notifications and Firebase Messaging use the same `medication` channel
  in `app.config.ts` / `firebase.json`; mismatched defaults previously stopped
  the Android manifest merge.
